RETRIEVAL QUALITY GATE

Lexical vs semantic vs hybrid RRF

This page runs the pinned local multilingual embedding model against a fixed Research Ledger corpus containing exact matches, paraphrases, multilingual questions, noise and distractors. It calculates Recall@5 and mean reciprocal rank without sending benchmark passages to the application backend.

Quality claims require an executed receipt. CI validates the corpus, metric math and integration contracts, but it does not download the ~browser model or manufacture semantic accuracy results. Run this page in a real browser before changing the default retrieval mode.
