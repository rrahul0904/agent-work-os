# Clean-room product provenance

This project is an independent implementation of a general product pattern: remotely controlling coding-agent CLIs that run on a developer-owned machine. The design was derived from public product behavior, public documentation, open standards, and independently written code.

It is **not** a fork of Vicoa and does not copy Vicoa source code, branding, protected assets, database migrations, or private APIs. Vicoa's public repository is AGPL-licensed; this repository intentionally uses a clean-room implementation and its own protocol, storage model, UI, and code organization.

The current differentiated direction is broader than remote chat: machine presence, multi-agent adapters, durable sessions, worktrees, tasks, PR/CI workflows, approvals, automation, cost/quality telemetry, and engineering-agent fleet governance.
